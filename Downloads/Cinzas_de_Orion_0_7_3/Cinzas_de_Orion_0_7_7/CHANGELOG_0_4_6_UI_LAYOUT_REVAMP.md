# Cinzas de Órion 0.4.6 — Revisão de Interface e Navegação

- Menu principal simplificado para nomes únicos.
- Removido acesso direto ao NEXUS do Menu; NEXUS permanece dentro da configuração da Manopla.
- Tela Equipamento reorganizada em quatro cartões de peça, cada um com configuração abaixo.
- Removidos atalhos duplicados de Álbum/Manopla/Projetos da lateral do conjunto.
- Tela Manopla agora mostra 3 slots normais + 1 slot especial reservado a cartas ÚNICAS.
- Histórico de navegação implementado para que ESC retorne sempre à tela de origem imediata.
- Layouts ajustados para evitar sobreposição de botões e textos.
- Slot especial da Manopla persistido no save, inicialmente vazio e reservado para conteúdo futuro.
