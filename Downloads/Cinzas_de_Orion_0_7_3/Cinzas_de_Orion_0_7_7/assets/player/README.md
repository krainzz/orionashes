# Sprites externos do protagonista

Coloque aqui os quatro PNGs-base, desenhados sem as peças que serão sobrepostas:

- `baixo.png`
- `cima.png`
- `esquerda.png`
- `direita.png`

O jogo estica cada PNG para **44 × 85 px** usando escala sem interpolação para preservar o pixel art. Um frame opcional de caminhada pode usar o sufixo `_1`, como `baixo_1.png`. Se ele não existir, o frame normal é reutilizado.

Os retratos do menu **Equipamento** e da tela de vitória usam `baixo.png`, junto com as camadas de equipamento disponíveis.
