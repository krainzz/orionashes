# Cinzas de Órion 0.4.6 — UI REVAMP 3

## Correções
- Diário voltou a listar missões com status `DISPONÍVEL` tratados visualmente como `EM ANDAMENTO` até a conclusão, evitando catálogo vazio quando a missão foi liberada mas ainda não aceita.
- Rolagem do Diário passou a ter scrollbar registrada funcionalmente.
- Rolagem do Status passou a ter scrollbar registrada e arrastável com o mouse.
- Inventário de materiais foi reconstruído como lista vertical rolável, sem a antiga grade comprimida.
- Lista de criaturas no Inventário também é rolável para suportar o crescimento futuro do bestiário.
- Scrollbars aceitam roda do mouse e arraste direto do cursor.
- Ao selecionar uma nova missão, o scroll dos detalhes é reiniciado no topo.
- Scrollbars antigas são limpas a cada frame para evitar áreas de interação obsoletas.

## Mantido
- Regras de combate e atributos da 0.4.6 permanecem inalterados.
- Menu e nomenclatura da UI da REVAMP 2 permanecem como base.
